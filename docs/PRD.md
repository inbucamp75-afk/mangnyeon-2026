# 사이트 설계도(PRD) — 2026 팀 망년회 (팀 이름 미정)

작성일: 2026-10-25 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
회사 팀·부서 망년회의 날짜·장소 후보를 보여 주고, 팀원들의 참석 여부와 가능한 날짜·장소를 받아 정하는 사이트.

## 2. 손님
- 누가: 같은 회사 팀·부서 팀원
- 어디서 알고 오나: 카카오톡 단톡방과 사내 메신저·메일로 받은 링크 → **폰·PC 둘 다** 편하게

## 3. 손님이 궁금한 것 (답하기 전에)
1. 날짜·장소 후보가 무엇인가
2. 언제까지 답해야 하나 (마감일)
3. 지금 다른 사람들은 어디가 많이 되나 (후보별 인원 수)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 후보별 가능 인원 수를 실시간으로 공개 (숫자만, 이름은 비공개)
- 후기: 해당 없음

## 5. 누르게 할 버튼 하나
- 버튼 이름: (미정 — 예: "참석 여부 남기기")
- 누르면: 응답 폼

## 6. 페이지 구성 (위에서 아래로, 한 장)
1. 첫 화면 — 망년회 한 문장 + 마감일 + 버튼
2. 날짜 후보 · 장소 후보 소개
3. 후보별 가능 인원 수 (숫자만)
4. 응답 폼
5. 마감 후 변경 안내 + 간사 연락처 · "회비 없음(회사 부담)" 한 줄

## 7. 응답 폼에서 받을 것
- 이름 (필수)
- 참석 / 불참 / 미정 (필수)
- 가능한 날짜 (후보 중 여러 개 체크)
- 가능한 장소 (후보 중 여러 개 체크 + "기타" 직접 입력)
- 한마디·요청 사항 (자유 입력, 예: 못 먹는 음식)
- 개인정보 수집·이용 동의 (필수 · 목적: 망년회 일정 정하기 · 보관: 망년회 후 삭제 여부는 간사가 정함)
- 같은 이름으로 다시 답하면 **마지막 답으로 바꾼다**

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 날짜 후보: 12/18(금) 저녁 · 12/22(화) 저녁
  - 처음엔 12/19(금)·12/23(화)로 말했으나 2026년 달력에서 요일이 맞지 않아 요일 기준으로 12/18·12/22로 고침
- 장소 후보: 울프강스테이크하우스 · 조조엔 · 기타(직접 입력)
- 투표 마감: **12/11(금) 오후 4시**
- 마감 후 변경 사항이 생기면: 간사에게 연락
- 간사 연락처: 000-1234
- 회비: 없음 (회사 부담)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인 (이름만 적고 답함)
- 결제·회비 걷기
- 알림 메일·문자
- 답을 Git 저장소에 저장 (공개 노출·키 관리 문제로 Supabase 사용)

## 10. 첫 화면 한 문장 후보
1. 올해도 수고 많았어요. 2026 망년회, 언제 어디서 만날까요?
2. 한 해를 따뜻하게 마무리할 날을 함께 정해요.
3. 12/11(금) 오후 4시까지, 가능한 날짜와 장소를 골라 주세요.

## 11. 다음에 할 것
- 최종 날짜·장소가 정해지면 첫 화면을 "확정 안내"로 바꾸기

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 연말 분위기를 **고급스럽게** · 크리스마스 트리와 흰 눈 이미지 (실제 사진 대신 클로드가 그린 일러스트·눈 내리는 효과, 과하지 않게)
- 참고 디자인: 없음 — 클로드가 정함
- 응답 저장: 예 → Supabase(leaderpl-admin 스킬 기준, 문의 표 대신 응답 표로 바꿔 적용) + /admin
  - 공개 화면: 후보별 인원 수만 (이름·한마디는 보이지 않음)
  - /admin(간사 비밀번호): 이름별 답·한마디 목록, 후보별 집계, CSV 내려받기
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소(코드·설계도만, 답 데이터는 넣지 않음) + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 응답 폼 → Supabase 저장 → 후보별 인원 수 공개 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
